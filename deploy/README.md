# Configuración y despliegue del VPS Linux

## Proyecto
Sistema Web de Ventas e Inventario

## Sistema operativo
Ubuntu Server 24.04 LTS

## Tecnologías previstas
- Java
- Apache Tomcat 10
- Nginx
- PostgreSQL
- Git y GitHub

## Responsabilidades
1. Configuración inicial del VPS.
2. Creación de usuarios y administración de permisos.
3. Configuración del acceso SSH.
4. Actualización del sistema operativo.
5. Configuración del firewall UFW.
6. Instalación de Java y Tomcat.
7. Configuración de Nginx como proxy inverso.
8. Publicación de la aplicación web.
9. Verificación del acceso mediante IP pública.
10. Documentación de comandos y evidencias.
